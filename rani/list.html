HTML List

Penjelasan

Tag list dalam HTML digunakan untuk membuat daftar urutan item. Terdapat dua jenis list utama, yaitu Ordered List (<ol>) untuk daftar berurutan menggunakan angka atau huruf, dan Unordered List (<ul>) untuk daftar tidak berurutan menggunakan simbol bullet. Setiap item di dalamnya dibungkus dengan tag <li>.

Syntax

<ol>
    <li>Item baris pertama</li>
</ol>

<ul>
    <li>Item baris pertama</li>
</ul>
