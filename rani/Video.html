HTML Video

Penjelasan

Tag <video> dalam HTML digunakan untuk menampilkan dan memutar berkas video langsung di dalam halaman web tanpa memerlukan plugin tambahan. Atribut "controls" wajib ditambahkan agar browser memunculkan tombol play, pause, dan pengatur suara.

Syntax

<video src="nama_video.mp4" controls>
    Browser Anda tidak mendukung tag video.
</video>
