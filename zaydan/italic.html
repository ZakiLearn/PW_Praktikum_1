HTML Italic

Pengertian

Italic (tag <i>) adalah elemen HTML yang digunakan
untuk menampilkan teks dengan gaya cetak miring tanpa memberikan penekanan nada atau makna tertentu (emphasis).

Syntax/Contoh Kode

	<!DOCTYPE html>
	<html>
	<body>
	
	<p>Istilah teknis: <i>software</i> dan <i>hardware</i>.</p>
	<p>Nama ilmiah dari kucing rumah adalah <i>Felis catus</i>.</p>
	
	</body>
	</html>

Hasil

Istilah teknis: software dan hardware

Nama ilmiah dari kucing rumah adalah Felis catus

Penjelasan

Tag <i> digunakan untuk mengubah gaya tampilan visual teks menjadi cetak miring (italic).
Tag ini biasanya digunakan untuk menandai kata dalam bahasa asing, istilah teknis, nama ilmiah/latin, atau dialog batin tokoh.
Berbeda dari tag <em>, tag <i> murni digunakan untuk membedakan gaya teks tanpa memberi penekanan intonasi khusus saat dibaca oleh screen reader.
