HTML Coloring

Pengertian

Coloring adalah pemberian warna pada teks atau elemen HTML
agar tampilan halaman web menjadi lebih menarik dan mudah digunakan.

Syntax/Contoh Kode

	<!DOCTYPE html>
	<html>
	<body>
	
	<p style="color: red;">Teks berwarna merah menggunakan nama warna</p>
	<p style="color: green;">Teks berwarna hijau menggunakan nama warna</p>
	<p style="color: blue>Teks berwarna biru menggunakan nama warna</p>
	<p style="color: #ff0000;">Teks berwarna merah menggunakan kode HEX</p>
	<p style="color: #00FF00;">Teks berwarna hijau menggunakan kode HEX</p>
	<p style="color: #0000FF;">Teks berwarna biru menggunakan kode HEX</p>:
	
	</body>
	</html>

Hasil

Teks berwarna merah menggunakan nama warna

Teks berwarna hijau menggunakan nama warna

Teks berwarna biru menggunakan nama warna

Teks berwarna biru menggunakan kode HEX

Teks berwarna biru menggunakan kode HEX

Teks berwarna biru menggunakan kode HEX

Penjelasan

Coloring digunakan untuk memberikan warna pada teks atau elemen HTML. Pewarnaan dapat dilakukan menggunakan atribut style dengan properti color.
Ada beberapa cara untuk menentukan warna, salah satunya dengan menggunakan nama warna dan kode warna HEX.

Pada contoh pertama, style="color: red;" digunakan untuk memberikan warna merah pada teks dengan menggunakan nama warna.

Pada contoh kedua, style="color: #0000FF;" digunakan untuk memberikan warna biru pada teks dengan menggunakan kode warna HEX.
