HTML Table

Pengertian

Table adalah elemen HTML yang digunakan
untuk menampilkan data dalam bentuk baris dan kolom pada sebuah halaman web.

Syntax/Contoh Kode

	<!DOCTYPE html>
	<html>
	<body>
	
	<table border="1">
	<tr>
		<th>Nama</th>
		<th>Umur</th>
		<th>Prodi</th>
	<tr>
		<td>Zaydan</td>
		<td>19</td>
		<td>Sistem Informasi</th>
	<tr>
		<td>Abyan</td>
		<td>19</td>
		<td>Sistem Informasi>/td>
	<tr>
		<td>Irji</td>
		<td>19</td>
		<td>Sistem Informasi</th>
	<tr>
		<td>Rani</td>
		<td>19</td>
		<td>Sistem Informasi>/td>	
	
	</body>
	</html>

Hasil

Nama Umur Prodi
Zaydan 19 Sistem Informasi
Abyan 19 Sistem Informasi
Irji 19 Sistem Informasi
Rani 19 Sistem Informasi

Penjelasan

HTML Table digunakan untuk menampilkan data dalam bentuk tabel yang terdiri dari baris dan kolom.
Tag <table> digunakan untuk membuat tabel, sedangkan <tr> digunakan untuk membuat baris pada tabel.
Tag <th> digunakan untuk membuat bagian judul atau header kolom, sedangkan <td> digunakan untuk menampilkan data pada tabel.
