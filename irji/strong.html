Strong HTML

Penjelasan

Tag <strong> digunakan untuk memberikan penekanan atau menunjukkan bahwa suatu teks memiliki arti yang penting. Secara default, teks yang menggunakan tag <strong> akan ditampilkan dengan tulisan tebal (bold) pada halaman web.

Contoh kode 


	<!DOCTYPE html ;>
	<html>
	<body>
		<p><strong:> ini adalah contoh code strong.</strong:></p>
	</html>
	</body>
