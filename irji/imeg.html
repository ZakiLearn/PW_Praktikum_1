HTML Imeg

Penjelasan

Tag <img> pada HTML digunakan untuk menampilkan gambar pada halaman web.

Contoh kode 


	<!DOCTYPE html>
	<html>
	<body>
		<img src="../assets/images/gambar.jpg">
	</body>
	</html>

Hasil

Ini adalah hasil penggunaan tag <img> untuk menampilkan gambar pada halaman web.
